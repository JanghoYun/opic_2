56AL 예시답변

56문항 모두 AL 목표(150~200단어)로 예시답변을 새로 쓰고, 문항마다 전개와 AL 포인트를 달았습니다.

AL을 받으려면 무엇이 달라야 하나요?

AL(Advanced Low)은 ACTFL 기준으로 문단 길이로 이어지는 말로 과거·현재·미래를 오가며 묘사하고 이야기할 수 있고, 예상치 못한 문제 상황(롤플레이 대안 제시)도 처리할 수 있는 수준입니다. 문장을 나열하는 IH/IM 답변과의 차이는 '길이'보다 연결과 구조에 있습니다.

  • 난이도: AL을 목표로 한다면 자기평가 5~6단계를 고르는 것이 일반적인 권장입니다. 이슈·비교처럼 어려운 질문이 나와야 AL 수준을 보여줄 기회가 생깁니다.
  • 길이: 답변당 1분 30초~2분, 150~200단어 정도를 연습 기준으로 삼으세요(공식 기준은 아님). 이 가이드의 예시답변은 모두 이 범위로 새로 썼습니다.
  • 구조: 도입(한 문장 요약) → 본론(구체 디테일 2~3개, 예시·짧은 일화) → 마무리(느낌·의견·현재와 연결).
  • 시제: 한 답변 안에서 현재(습관) + 과거(경험) + 현재완료/미래(변화·계획)를 섞으세요. 과거 습관은 used to/would로 말합니다.
  • 연결어: 시간 At first · After that · By the time / 대조 However · On the other hand · That said / 결과 So · That's why · ended up / 예시 For example · like / 의견 Honestly · In my opinion · Overall

유형별 전개 공식

  • 묘사·장소: 전체 인상 → 위치·규모 → 구성 요소(공간 이동) → 특별한 점 → 내 느낌
  • 습관·일상: 빈도·시간 → 상황별 활동(누구와·무엇을·왜) → 의미
  • 과거 경험·문제: 언제·어디·누구 → 문제 발생 → 해결 과정 → 결과 → 교훈(Since then…)
  • 비교: 과거(used to/would) → 계기 → 현재 → 장단점 인정(That said) → 결론
  • 롤플레이 질문: 인사·상황 → 질문 3~4개(질문마다 이유 한 줄) → 마무리
  • 롤플레이 대안: 사과 → 구체적 이유 → 대안 3개 이상(각각 근거) → 보상 제안 → 상대의 선택 요청
  • 이슈: 공감 → 문제 사례 → 반대 측면(On the other hand) → 내 의견과 해결책

자주 점수를 깎는 습관: 1분 미만의 짧은 답 · 현재시제만 사용 · 질문과 다른 내용(습관을 묻는데 한 번의 경험만 말하기 등) · 질문과 어긋나는데 지나치게 매끄러운 암기 답변.

연습법: 예시답변을 통째로 외우지 말고 ① 질문 듣기 → ② '전개'만 보고 내 경험으로 녹음 → ③ 예시답변과 비교하며 빠진 연결어·시제 체크 → ④ 같은 질문을 다시 녹음하세요. 예시 속 인물(Harry, 아내, 친구 민수·지수)과 경험은 연습용 설정이므로 본인 이야기로 바꾸세요.

질문·예시답변 듣기

질문은 Ava, 예시답변은 Andrew 목소리의 신경망 음성(미리 생성한 MP3)으로 재생됩니다. 어느 기기에서나 같은 품질로 들리며, 파일을 불러오지 못하면 기기의 합성음성으로 대체합니다. 속도를 바꿔도 음 높이는 유지됩니다.

추천 연습: 질문만 듣고 내 답변 녹음 → 예시답변을 0.9배로 들으며 따라 말하기(섀도잉) → 1배로 다시 녹음.

듣기 버튼을 누르면 재생돼요.

주제별 질문과 답변

각 질문 아래에 AL 포인트가 있고, AL 예시답변은 펼쳐서 볼 수 있어요. 먼저 전개만 보고 내 답변을 녹음한 뒤 비교하세요.

녹음 저장 방식 · 시험 조사 자료

페이지를 닫아도 내 녹음을 다시 듣기

질문마다 최근 녹음 1개를 이 브라우저의 저장소(IndexedDB)에 보관합니다. 같은 기기·같은 브라우저에서 같은 사이트를 다시 열면 불러옵니다. 서버나 GitHub에 녹음을 업로드하지 않아 별도 서버는 필요하지 않습니다.

다른 기기·브라우저와 동기화되지 않습니다. 사이트 데이터 삭제·시크릿 모드 종료·저장 공간 부족이나 브라우저 정책으로 지워질 수 있어요. 중요한 녹음은 내려받아 백업하세요. 저장 실패 시 화면에 알리며, 그 녹음은 현재 탭에서만 들을 수 있습니다.

마이크 권한을 허용해야 녹음할 수 있습니다. HTTPS GitHub Pages를 일반 Safari/Chrome 등에서 여세요. 앱 안 브라우저에서 녹음이 안 되면 외부 브라우저로 여세요. 녹음 중에는 다른 질문 녹음·TTS를 잠시 막고, 다른 화면으로 이동하면 녹음을 멈춥니다.

브라우저 저장소 확인 중이에요.

유지 요청이 허용되어도 사이트 데이터 삭제를 막거나 백업을 대신하지 않습니다. 이 저장 기능은 이 가이드에서 새로 녹음한 답변에만 적용되며, 기존 모의고사의 임시 녹음을 옮기지 않습니다.

저장 방식 참고: IndexedDB · 브라우저 저장 한도와 삭제 정책

시험 조사와 이번 업데이트

국내 OPIc 공식 안내: 12~15문항, 본 시험 40분(OT 포함 약 60분). 사전 설문과 자기평가를 통해 질문이 맞춤 구성되며, 전체 발화를 종합해 평가합니다. 공식 시험소개

평가의 핵심: 기능·과제 수행, 정확성, 내용·맥락, 발화의 길이·조직을 함께 봅니다. 단어 수나 암기한 답변만으로 등급을 보장할 수 없습니다. ACTFL 안내

연습 방향: 익숙한 대상 묘사와 일상, 과거 사건의 순서·결과, 과거와 현재 비교, 정보 질문, 문제 설명과 대안을 연습합니다. 롤플레이는 질문 상황과 그에 대한 문제 상황을 함께 연습하도록 추가했습니다. LTI 안내서

자료 해석: ACTFL 전 세계 시험 안내와 국내 운영 안내는 등급 범위·운영 설명이 다를 수 있어, 위 시간과 문항 수는 국내 공식 안내를 따랐습니다. 비공식 학습 글은 유형 분류 참고, 응시자 글은 개인 경험 참고일 뿐입니다.

새 28문항은 직접 작성한 예상 연습문제입니다. 공식 기출·유출문제·출제 확률 목록이 아니며, 목표 등급은 AL로 가정했습니다. 예시답변은 AL 목표에 맞춰 모두 150~200단어 문단으로 다시 썼습니다(기존 답변은 평균 약 75단어로 IM 수준이었습니다). 기존 답변의 문법 오류와 질문과 어긋난 내용도 바로잡았습니다. 날씨·교통·재활용·스마트폰은 폭넓은 일상 소재 연습용이며 실제 출제를 보장하지 않습니다.

56문항 전체 연습은 실제 12~15문항 시험 재현이 아닌 질문은행 연습입니다. 예시의 이름·가족·거주지·경험은 사용자 사실 확인을 거친 정보가 아닙니다. 그대로 외우기보다 본인의 경험으로 바꿔 말하세요. ACTFL은 즉흥적이고 암기하지 않은 말하기 능력을 평가한다고 안내합니다.
